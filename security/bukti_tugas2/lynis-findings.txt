1. REMAINING WARNINGS (DISCLOSED TRANSPARENTLY)
------------------------------------------------------------

* Warning 1: [KRNL-5830]
  Text     : Reboot of system is most likely needed
  Solution : reboot (https://cisofy.com/lynis/controls/KRNL-5830/)
  Analysis : Pustaka inti dan komponen kernel menerima pembaruan paket selama
             sesi hardening. Pada lingkungan lab sementara (Iximiuz Labs),
             eksekusi reboot penuh akan menghentikan container/VM sandbox dan
             menghapus sesi kerja. Oleh karena itu, kebutuhan reboot dicatat
             secara transparan tanpa manipulasi.

* Warning 2: [PKGS-7392]
  Text     : Found one or more vulnerable packages.
  Solution : apt-get update && apt-get upgrade / unattended-upgrades
             (https://cisofy.com/lynis/controls/PKGS-7392/)
  Analysis : Pembaruan paket dasar telah diaplikasikan (`apt update`). Kerentanan
             yang tersisa bergantung pada rilis patch resmi hulu (upstream)
             dari pengelola distribusi Debian/Ubuntu yang belum tersedia di repositori.
             Dokumentasi mencatat ini sebagai item pemeliharaan berkala (patch management).

* Warning 3: [FIRE-4512]
  Text     : iptables module(s) loaded, but no rules active
  Solution : Konfigurasi rule firewall aktif (https://cisofy.com/lynis/controls/FIRE-4512/)
  Analysis : Modul kernel iptables terdeteksi aktif, namun tabel ruleset filter
             kosong karena kebijakan isolasi port dilakukan pada tingkat boundary/routing
             lab. Pada lingkungan deployment penuh, UFW / iptables ruleset diaktifkan
             untuk menutup port selain SSH (22) dan Web (80/443).
